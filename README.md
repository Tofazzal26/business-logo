
# Business Logo - FAQ & Contact Page

This project is a modern web application built with Next.js and TypeScript, styled using TailwindCSS and DaisyUI.
It provides an elegant FAQ (Frequently Asked Questions) section and a Contact Section for users to get in touch easily.

### Live Link --> [Business-Logo](https://business-logo.vercel.app)

### ✨ Features

- FAQ Section with collapsible questions & answers.

- Contact Section with call-to-action button.

- Responsive Design (Mobile, Tablet, Desktop).

- Modern UI using TailwindCSS and DaisyUI components.

- Clean & Maintainable Codebase with TypeScript.

### 🛠️ Tech Stack

- Next.js (App Router)
- TypeScript
- TailwindCSS
- DaisyUI


### 🚀 Getting Started

Clone the project

```bash
  git clone https://github.com/Tofazzal26/business-logo.git
```

Go to the project directory

```bash
  cd business-logo
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```
